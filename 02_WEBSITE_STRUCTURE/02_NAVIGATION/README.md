# 02_NAVIGATION

## Purpose

This folder defines how users should move through the Atrellis website.

Its role is to explain:
- what should appear in main navigation,
- how navigation should be prioritized,
- what belongs in header versus footer,
- how users should move between sections,
- and how navigation should support conversion, clarity, and discovery.

This folder is important because even a good sitemap can fail if navigation feels cluttered or unclear.

## What belongs here

- Navigation structure
- Header logic
- Footer logic
- Priority order of menu items
- Navigation simplification rules
- Discovery and conversion pathways

## What does not belong here

- Detailed page layouts
- Full CTA copy libraries
- Route implementation code
- Component styling details
- Long-form user journey maps

Those belong elsewhere.

## Core files in this folder

- `NAVIGATION_SYSTEM.md`
- `HEADER_AND_FOOTER_LOGIC.md`
- `MENU_PRIORITY_RULES.md`
- `NOTES.md`

## Source of truth

The main source of truth is:

- `NAVIGATION_SYSTEM.md`

## Usage rules

- Navigation should reduce confusion, not display everything.
- Top-level navigation should stay disciplined.
- Make important user paths obvious.
- Navigation should support both discovery and action.

## Relationship to other folders

This folder supports:
- `01_SITE_MAP/`
- `03_USER_JOURNEYS/`
- `04_CTA_SYSTEM/`
- `03_PAGE_SYSTEM/`
