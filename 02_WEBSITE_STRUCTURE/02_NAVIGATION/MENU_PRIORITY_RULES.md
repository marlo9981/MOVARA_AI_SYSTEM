# Menu Priority Rules

## Purpose

This file defines what deserves top-level visibility in the navigation.

## Priority order

### Priority 1: Main conversion-support pages
These are the pages most users need to understand the site:
- Services
- Products / Systems
- Projects / Blog
- About
- Contact

### Priority 2: Inquiry access
A clear action path should remain visible.

### Priority 3: Important supporting discovery
Use footer, internal links, or selective dropdowns for:
- service-category pages
- trust-support pages
- content clusters
- future tools or special flows

## What should not be top-level too early

Avoid making these top-level immediately unless the site grows significantly:
- every category page
- every project type
- every support article
- every trust-related page
- every future platform flow

## Priority rule

Top-level nav should answer:
- where do I start?
- where do I go if I know what I want?
- how do I contact you?

If a menu item does not help with those questions, it may not belong at the top level.

## Growth rule

As the website expands, increase navigation depth carefully.

Use:
- better grouping,
- stronger internal linking,
- and selective footer depth

before increasing top-level clutter.
