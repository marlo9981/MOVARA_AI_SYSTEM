# Navigation System

## Core principle

The Atrellis navigation should feel simple, premium, and intentional.

It should not try to show the entire information architecture at once.

The goal is to help users:
- understand where they are,
- find the right area quickly,
- and move toward inquiry with low friction.

## Recommended top-level navigation

Use a small set of high-value items:

- Services
- Products / Systems
- Projects / Blog
- About
- Contact

Home should be accessible through the logo.

## Why this works

This structure balances:
- clarity
- breadth
- authority
- and conversion

It avoids turning the navigation into a crowded index of every category.

## Navigation behavior rule

Navigation should help with three main outcomes:

### 1. Fast understanding
Users should quickly grasp the main shape of the website.

### 2. Relevance discovery
Users should be able to move from broad pages into more relevant category areas.

### 3. Conversion support
Users should always have a visible path toward action.

## Dropdown rule

Use dropdowns only when they improve clarity.

Do not create oversized mega-menus too early unless the content volume truly requires it.

## Mobile rule

Mobile navigation should stay clear and lightweight.
Prioritize:
- main page groups
- strong contact/inquiry access
- easy return to key content areas

## Navigation warning

A broad business often becomes hard to navigate because too much is exposed too early.

Atrellis should hide complexity behind clear grouping.
