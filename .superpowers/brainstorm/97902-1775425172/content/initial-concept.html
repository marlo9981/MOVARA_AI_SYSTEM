Agentic Duplication: Initial Concept

Defining the scope of the automation

A

Full Project Cloning

Clone entire folders (like Task.Ahlian), rename packages, update imports, and initialize new project metadata.

B

Agent Rule Duplication

Inject specialized CLAUDE.md and AGENTS.md rules into existing projects to make them "agent-ready".

C

Hybrid / "Scaffold"

A "Movara Project Generator" that creates the structure AND the agent rules from scratch.
