# MOVARA AI Agents System

This directory contains the agent system code for the MOVARA AI platform, including specialized AI agents, workflows, tools, and tests.

## Directory Structure

- `/agents` - Specialized AI agents for different domains (Engineering, Marketing, Design, etc.)
- `/workflows` - Workflow definitions and orchestration logic
- `/tools` - Utility functions and integrations used by agents
- `/tests` - Test files for agents, workflows, and tools

## Agent Categories

Based on the existing structure, agents are organized into these categories:
- Consulting (BusinessStrategist, CaseStudyBuilder, etc.)
- Content (BlogWriter, ContentRepurposer, etc.)
- Design
- Engineering (BackendSpecialist, DevOpsEngineer, etc.)
- Marketing
- Operations
- Product

Each agent has specific capabilities and responsibilities within the MOVARA AI ecosystem.
