# 01_SERVICE_CATEGORY_OVERVIEW

## Purpose

This folder defines the role, scope, and quality bar for the Atrellis service category system.
It is the reference point for how we group services so the website feels broad but controlled, conversion‑focused, and ready to evolve into a platform.

## Files

- **01_SERVICE_CATEGORY_OVERVIEW.md**
  Source of truth for why the service category layer exists and how it should behave over time.

- **02_SCOPE_AND_ROLE.md**
  Defines what is in and out of scope for this system, and how it connects to brand, ICP, and journeys.

- **03_CATEGORY_SUCCESS_CRITERIA.md**
  Lists the clarity, control, conversion, and expansion criteria every category must meet.

- **NOTES.md**
  Working assumptions, open questions, and placeholders for future decisions.

## How to Use This Folder

- Start here whenever you are:
  - proposing a new service category
  - renaming or merging categories
  - deciding if something should be a category vs a sub‑service vs a standalone page
- Use the success criteria as a checklist before committing structural changes.
- Keep NOTES.md updated when decisions are deferred or assumptions change.
