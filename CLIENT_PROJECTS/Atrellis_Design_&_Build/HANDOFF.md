# HANDOFF.md — Atrellis Design & Build

## Project Lifecycle & Milestones

This project follows the **"Pages First, Services Second, Platform Third"** operating rule.

### Milestone 1: Discovery, Sitemap & Positioning (PLANNING)
**Goal:** Establish the brand authority and conversion architecture.
- [ ] Define Brand Voice and Positioning (`01_BRAND_FOUNDATION/`).
- [ ] Create Sitemap and Navigation Map (`02_WEBSITE_STRUCTURE/`).
- [ ] Establish "Editorial Brain" Strategy (`05_CONTENT_SEO_AIO/05_BLOG_ENGINE/`).
- [ ] Build high-conversion wireframes for core pages.

### Milestone 2: UI/UX Design System & Animation Strategy
**Goal:** Create the "Architectural Reveal" visual identity.
- [ ] Define the "Premium Architectural" Design System (Slate/Stone/Zinc).
- [ ] Prototype GSAP/ScrollTrigger reveal effects (`09_BUILD_SYSTEM/06_ANIMATION_SYSTEM/`).
- [ ] Create placeholder and asset map (`06_MEDIA_LIBRARY_PLAN/`).

### Milestone 3: Core Build (Website MVP)
**Goal:** Launch high-performance, conversion-optimized site.
- [ ] Implement Next.js App Router for core pages (`03_PAGE_SYSTEM/`).
- [ ] Build deep service silos for initial categories (`04_SERVICE_CATEGORY_SYSTEM/`).
- [ ] Integrate Supabase for lead capture and RLS protection.
- [ ] Implement "Gated Before/After Gallery" for lead magnet logic.

### Milestone 4: The Playbook Features (Lead Gen Engine)
**Goal:** Validate the "superior automation" differentiator.
- [ ] Build the **Product Configurator** (Zipblinds, Roofing).
- [ ] Implement the **Instant Quote Engine** (Logic + Lead Capture).
- [ ] Setup Lead Dashboard in Supabase.

### Milestone 5: AI Client Experience
**Goal:** Automate qualification and high-touch follow-ups.
- [ ] Implement AI Chat/Assistant for pre-qualification (`07_AI_CLIENT_EXPERIENCE/`).
- [ ] Setup automated follow-up sequences.
- [ ] Integrate Telegram notifications for instant sales handoff.

### Milestone 6: Platform Scaling (Phase 2 Roadmap)
**Goal:** Transition from website to business operations platform.
- [ ] Initialize Customer Portal architecture (`10_PLATFORM_FUTURE/`).
- [ ] Expand configurator to include floorplan-to-render flows.
- [ ] Scalable admin dashboard for project management.

---

## Acceptance Criteria (Phase 1)

- **Performance:** <1s LCP (Lighthouse Score >90).
- **SEO:** Zero placeholder copy; verified topic clusters for all 6 core categories.
- **Conversion:** Working lead flow (Form -> Supabase -> Notification).
- **Design:** "Architectural Reveal" animations applied to all core landing pages.
