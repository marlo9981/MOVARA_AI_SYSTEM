# Header and Footer Logic

## Header role

The header should do three things:

1. orient the user
2. provide access to key page groups
3. keep inquiry or contact action easy to find

## Header recommendations

### Left side
- Atrellis logo
- click returns to Home

### Main navigation
- Services
- Products / Systems
- Projects / Blog
- About
- Contact

### Utility action
- inquiry CTA
- or contact shortcut if needed

## Header rule

Keep the header focused.
Do not overload it with every category or every utility link.

## Footer role

The footer should carry:
- secondary navigation
- support links
- trust-support references
- partner/supplier references where appropriate
- contact information
- category pathways if useful

## Footer recommendations

The footer can include:

### Company
- About
- Contact
- possible future process or trust links

### Services / Systems
- major categories
- selected high-value category links

### Content
- Projects
- Blog
- FAQs if added later

### Trust / Ecosystem
- partner or supplier references
- reassurance support
- ecosystem links if appropriate

## Footer rule

The footer can carry more depth than the header, but it should still remain clean and grouped.

The footer should help users recover orientation, not present chaos.
