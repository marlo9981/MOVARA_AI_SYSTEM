# 01_SITE_MAP

## Purpose

This folder defines the overall site map for Atrellis.

Its role is to explain:
- what pages exist,
- how pages are grouped,
- which pages are primary,
- which pages are supporting,
- what future pages may exist later,
- and how the website should scale without becoming messy.

This folder is the structural blueprint for the public-facing website.

## What belongs here

- Master sitemap
- Page hierarchy
- Parent-child page relationships
- Current versus future route planning
- Structural explanation of main page groups

## What does not belong here

- Detailed wireframes
- Full navigation microcopy
- Component-level layouts
- Keyword mapping by page
- Technical route implementation details

Those belong elsewhere.

## Core files in this folder

- `MASTER_SITE_MAP.md`
- `PAGE_HIERARCHY.md`
- `FUTURE_ROUTE_EXPANSION.md`
- `NOTES.md`

## Source of truth

The main source of truth is:

- `MASTER_SITE_MAP.md`

## Usage rules

- Keep the sitemap clear and scalable.
- Avoid creating unnecessary pages too early.
- Use the sitemap to clarify structure, not to force content inflation.
- Distinguish between pages that exist now and pages planned for later.
