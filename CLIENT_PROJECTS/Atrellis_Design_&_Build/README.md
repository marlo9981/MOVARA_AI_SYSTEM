# Atrellis Design & Build — The Renovation Playbook

## Overview

Atrellis Design & Build is a premium, design-led renovation agency in Singapore specializing in balcony and outdoor-living solutions (Zipblinds, Roofing, Waterproofing). This project serves as the **Foundational Playbook** for the Movara AI "Renovation & Home Services" vertical.

The goal is to deliver a high-conversion website followed by an AI-driven platform that automates lead qualification and quoting, positioning Atrellis as the technical authority in the market.

## Core Differentiators

- **Superior UI/UX:** Architectural Reveal animations using GSAP and ScrollTrigger.
- **Conversion-First Strategy:** Lead-capture gating for before/after galleries and instant quotes.
- **AI-Driven Experience:** Integrated Product Configurator and Instant Quote Engine.
- **Content Engine:** Centralized SEO "Editorial Brain" for rapid topic clustering and AIO (AI Overview) dominance.

## Tech Stack

- **Frontend:** [Next.js 15+](https://nextjs.org/) (App Router, Server Components)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) (Architectural Theme: Slate, Stone, Zinc)
- **Animations:** [GSAP](https://gsap.com/) + ScrollTrigger
- **Backend/Database:** [Supabase](https://supabase.com/) (Auth, PostgreSQL, RLS)
- **Deployment:** [Vercel](https://vercel.com/) (Edge Runtime)
