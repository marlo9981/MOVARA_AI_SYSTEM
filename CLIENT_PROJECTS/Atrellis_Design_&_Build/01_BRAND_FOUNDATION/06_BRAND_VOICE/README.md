# 06_BRAND_VOICE

## Purpose

This folder defines how Atrellis should sound.

Its role is to make sure the brand voice is:
- consistent,
- clear,
- premium,
- trustworthy,
- and usable across pages, content, prompts, AI outputs, and future platform touchpoints.

This folder is important because even a strong strategy can feel weak if the language sounds generic, noisy, or inconsistent.

## What belongs here

- Brand voice principles
- Tone guidance
- Messaging do and don't rules
- Writing style rules
- Example phrasing patterns
- Voice calibration for different contexts

## What does not belong here

- Full homepage copy
- Full blog articles
- Technical prompt syntax only
- Random headline ideas without voice guidance
- Generic marketing filler

Those belong elsewhere.

## Core files in this folder

- `BRAND_VOICE_GUIDELINES.md`
- `MESSAGING_DO_AND_DONT.md`
- `TONE_EXAMPLES.md`
- `NOTES.md`

## Source of truth

The main source of truth is:

- `BRAND_VOICE_GUIDELINES.md`

## Usage rules

- The voice should sound premium and modern, but still human.
- It should be clear before clever.
- It should avoid generic contractor language and generic startup language.
- It should support trust, structure, and lower-friction decision-making.

## Relationship to other folders

This folder supports:
- all page-system copy
- all service and category content
- all CTA writing
- all SEO/AIO content
- all prompts and agent writing rules

Brand voice should be consistent across the full Atrellis system.
