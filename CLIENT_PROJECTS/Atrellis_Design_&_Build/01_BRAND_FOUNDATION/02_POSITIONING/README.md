# 02_POSITIONING

## Purpose

This folder defines how Atrellis should be positioned in the market.

Its job is to explain:
- how Atrellis should be framed,
- what makes it strategically valuable,
- how it should be distinguished from typical competitors,
- and what core narrative should guide messaging across the website and wider project.

This folder should turn the broad brand idea into a sharp strategic stance.

## What belongs here

- Core positioning statements
- Positioning pillars
- Category framing
- Strategic value narrative
- Comparative framing against common market alternatives

## What does not belong here

- Deep persona documents
- Full offer packaging
- Long page copy drafts
- Technical build details
- Raw brainstorming with no clear strategic value

Those belong in other folders.

## Core files in this folder

- `POSITIONING_STATEMENT.md`
- `POSITIONING_PILLARS.md`
- `CATEGORY_FRAMING.md`
- `NOTES.md`

## Source of truth

The main source of truth is:

- `POSITIONING_STATEMENT.md`

If another document conflicts with it, update that document unless the positioning has intentionally changed.

## Usage rules

- Keep positioning specific and believable.
- Avoid generic lines like "we provide excellence" or "we are customer-centric."
- Positioning must connect to both website conversion and long-term platform direction.
- If a claim cannot be supported later, do not make it a positioning pillar.
