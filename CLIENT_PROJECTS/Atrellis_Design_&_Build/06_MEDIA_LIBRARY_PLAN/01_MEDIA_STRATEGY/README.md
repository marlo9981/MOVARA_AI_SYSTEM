# 01_MEDIA_STRATEGY

## Purpose
This folder defines the overall visual strategy for the Atrellis website — what types of media are needed, how they support conversion goals, and the framework for prioritizing visual assets.

## What Belongs Here
- Master media strategy document
- Visual priority framework (what matters most and why)
- Media role mapping by page type
- Strategic decisions about photography, video, and illustration

## What Does NOT Belong Here
- Individual asset files → `07_RAW_ASSETS/`, `08_EDITED_ASSETS/`, `09_EXPORTS_FOR_WEB/`
- Naming rules → `02_NAMING_CONVENTIONS/`
- Specific hero images → `03_HERO_MEDIA/`
- Page-level media assignments → `04_PAGE_MEDIA/`

## Files in This Folder

| File | Role |
|---|---|
| `MEDIA_STRATEGY_MASTER.md` | SOURCE OF TRUTH — overall media strategy, goals, and principles |
| `VISUAL_PRIORITY_FRAMEWORK.md` | Ranking system for which visuals matter most and why |
| `MEDIA_ROLE_BY_PAGE.md` | What type of media each page needs and what job it does |
| `NOTES.md` | Rough working notes, open questions, and early-stage thinking |

## Related Folders
- `03_HERO_MEDIA/` — hero and banner visuals
- `04_PAGE_MEDIA/` — page-level media assignments
- `06_PROJECT_MEDIA/` — project photography and case study visuals
- `09_EXPORTS_FOR_WEB/` — final web-optimized exports
