## Purpose

Map what type of media each page needs and what job that media does for the visitor.

---

## Page Media Requirements

### Homepage

| Visual | Role | Priority |
|---|---|---|
| Hero image | First impression, emotional hook | P0 |
| Proof section (3-4 project shots) | Immediate credibility | P0 |
| Service category icons/images | Quick service scanning | P1 |
| Team photo or founder image | Humanize the brand | P1 |
| Trust badges/logos | Social proof | P1 |

### Services Index Page

| Visual | Role | Priority |
|---|---|---|
| Page hero | Set context for service range | P1 |
| Service category thumbnails | Visual scanning aid | P1 |
| Representative project shots | Prove capability per category | P1 |

### Individual Service Pages

| Visual | Role | Priority |
|---|---|---|
| Service hero | Specific to this service | P0 |
| Process images (2-3) | Show how it works | P1 |
| Before/after examples | Prove results | P0 |
| Product/material photos | Show what's used | P2 |
| Detail shots | Prove quality | P1 |

### Projects Gallery

| Visual | Role | Priority |
|---|---|---|
| Project thumbnails | Browse and filter | P0 |
| Full project images | Deep review | P0 |
| Before/after pairs | Transformation proof | P0 |

### Individual Project Pages

| Visual | Role | Priority |
|---|---|---|
| Project hero | Best shot of the project | P0 |
| Before photos | Establish starting condition | P0 |
| Process photos | Show the work | P1 |
| After photos | Show the result | P0 |
| Detail shots | Prove quality | P1 |
| Comparison pairs | Direct transformation | P0 |

### About Page

| Visual | Role | Priority |
|---|---|---|
| Team/founder photos | Build personal trust | P1 |
| Office/workspace | Establish legitimacy | P2 |
| Company history images | Tell the story | P2 |

### Contact Page

| Visual | Role | Priority |
|---|---|---|
| Map or location image | Help find us | P2 |
| Team photo | Reduce contact anxiety | P2 |

---

## Media Job Definitions

| Job | What It Does |
|---|---|
| Hook | Grab attention in first 3 seconds |
| Prove | Show evidence of capability |
| Explain | Make complex things clear |
| Humanize | Show the people behind the brand |
| Reassure | Reduce anxiety and build trust |
| Guide | Help navigation and scanning |
