## Purpose

This is the canonical source of truth for all project-related media at Atrellis. It defines what project media is needed, how it should be captured, how it maps to the website, and how it supports the sales and trust-building engine.

Project media is the single most important visual asset category for conversion. Before/after shots, detail photos, and completed project galleries are what convince prospects that Atrellis can deliver.

---

## What Counts as Project Media

Any visual asset that documents a specific completed (or in-progress) Atrellis project:

- Before photos (existing condition)
- During/construction photos (process shots)
- After photos (completed work)
- Detail shots (materials, finishes, craftsmanship)
- Wide/establishing shots (full project view)
- Client testimonial photos (if applicable)
- Floor plans or design renders (if applicable)

---

## Project Media Standards

### Minimum Shot Requirements Per Project

| Shot Type | Minimum | Purpose |
|---|---|---|
| Before (wide) | 1 | Show starting condition |
| Before (detail) | 1 | Show specific problem area |
| During (process) | 2 | Show work in progress, build trust |
| After (wide) | 2 | Show completed result from multiple angles |
| After (detail) | 3 | Show quality of finishes and materials |
| After (lifestyle) | 1 | Show the space being used/enjoyed |

**Minimum total per project: 10 photos**

### Quality Standards

- Resolution: minimum 3000px on longest edge (raw capture)
- Format: RAW or highest quality JPEG from camera
- Lighting: natural light preferred; avoid harsh flash
- Composition: straight lines, no distracting elements
- Consistency: same lens/angle for before/after pairs
- File naming: follow conventions in `02_NAMING_CONVENTIONS/`

## Project Media by Category

Different project types require different visual emphasis:

| Category | Visual Priority | Key Shots |
|---|---|---|
| Balcony Enclosure | Before/after transformation | Wide before, wide after, glass detail, view preservation |
| Waterproofing | Problem/solution | Leak evidence, membrane install, finished surface |
| Roofing | Scale and finish | Wide roof shot, edge detail, material close-up |
| Blinds/Zip Track | Product in context | Installed view, mechanism detail, lifestyle shot |
| Full Renovation | Full transformation | Before room, during demolition, after room, detail finishes |

See `PROJECT_SHOT_CATEGORIES.md` for complete breakdown.

## How Project Media Maps to the Site

| Site Location | Media Type | Purpose |
|---|---|---|
| Homepage — Proof Section | 3-4 hero project shots | Immediate credibility |
| Projects Gallery | Full project sets | Browse and filter by category |
| Individual Project Pages | Complete project media | Deep dive for high-intent visitors |
| Service Pages | Relevant project examples | Prove capability in each service |
| Case Studies | Full narrative + media | Detailed proof for consideration stage |
| Social Media | Cropped/optimized versions | Ongoing marketing content |

## Workflow: From Site to Site

1. **Capture** — photographer shoots on site (raw files → `07_RAW_ASSETS/`)
2. **Edit** — cull, retouch, color correct (`08_EDITED_ASSETS/`)
3. **Export** — web-optimized versions (`09_EXPORTS_FOR_WEB/`)
4. **Map** — assign to page slots and project entries (`10_PLACEHOLDER_MAP/`)
5. **Deploy** — assets go to `public/assets/projects/` in repo
