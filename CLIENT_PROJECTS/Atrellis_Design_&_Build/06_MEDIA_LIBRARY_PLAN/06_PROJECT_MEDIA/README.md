# 06_PROJECT_MEDIA

## Purpose
This folder stores all visual assets, shot lists, and media requirements specifically tied to Atrellis's completed projects — the proof-of-work that builds trust and converts visitors into leads.

## What Belongs Here
- Project photography (before/after, detail shots, wide angles)
- Case study visual requirements and shot lists
- Categorization of project types (balcony, renovation, roofing, etc.)
- Asset slot maps showing where each project image lives on the site
- Quality standards for project photography

## What Does NOT Belong Here
- Hero images for homepage or landing pages → `03_HERO_MEDIA/`
- General page media (team photos, office shots) → `04_PAGE_MEDIA/`
- Service-specific media (product shots, installation diagrams) → `05_SERVICE_MEDIA/`
- Raw unedited files → `07_RAW_ASSETS/`
- Web-optimized exports → `09_EXPORTS_FOR_WEB/`

## Files in This Folder

| File | Role |
|---|---|
| `PROJECT_MEDIA_MASTER.md` | SOURCE OF TRUTH — canonical guide for all project media requirements, standards, and usage |
| `PROJECT_SHOT_CATEGORIES.md` | Shot list taxonomy: what types of photos each project needs, organized by category |
| `CASE_STUDY_VISUAL_REQUIREMENTS.md` | Visual requirements for case study pages: layout, image counts, before/after standards |
| `NOTES.md` | Rough working notes, open questions, and early-stage thinking |

## Related Folders
- `03_HERO_MEDIA/` — hero and banner visuals for key pages
- `04_PAGE_MEDIA/` — general page-level media
- `05_SERVICE_MEDIA/` — service and product-specific media
- `08_EDITED_ASSETS/` — edited and retouched versions of project photos
- `09_EXPORTS_FOR_WEB/` — final web-optimized exports ready for deployment
