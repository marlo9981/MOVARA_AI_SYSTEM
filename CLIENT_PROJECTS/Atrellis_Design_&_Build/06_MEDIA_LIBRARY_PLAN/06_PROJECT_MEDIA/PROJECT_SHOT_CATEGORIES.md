## Purpose

Define the shot categories and minimum requirements for each type of Atrellis project. This ensures every project captured has the visual assets needed for the website, marketing, and sales materials.

---

## Shot Category Definitions

### 1. Establishing Shots
- **What:** Wide-angle views showing the full project scope
- **When:** Before and after
- **Purpose:** Give immediate context of what was done
- **Examples:** Full balcony view, entire roof, complete renovated room

### 2. Detail Shots
- **What:** Close-ups of materials, finishes, joints, and craftsmanship
- **When:** After completion (primarily)
- **Purpose:** Prove quality and attention to detail
- **Examples:** Glass panel edge, waterproofing membrane seam, blind mechanism, tile grout line

### 3. Process Shots
- **What:** Photos taken during construction/installation
- **When:** During active work
- **Purpose:** Show professionalism, process, and what's happening behind walls
- **Examples:** Crew at work, material staging, structural work, membrane installation

### 4. Before Shots
- **What:** Documentation of existing condition before work begins
- **When:** Before any work starts
- **Purpose:** Establish the problem and create transformation contrast
- **Examples:** Cracked balcony floor, water stains, old worn-out blinds, leak marks

### 5. After/Lifestyle Shots
- **What:** The completed space being used or enjoyed
- **Purpose:** Help prospects visualize themselves in the space
- **Examples:** Furniture on new balcony, rain test on waterproofed area, blinds drawn for privacy

### 6. Comparison Pairs
- **What:** Before and after from the same angle
- **Purpose:** Direct transformation proof — the most powerful conversion asset
- **Requirement:** Must be same lens, same angle, same framing

## Shot Requirements by Project Type

### Balcony Enclosure / Glass Balustrade

| Category | Minimum Shots | Notes |
|---|---|---|
| Before (wide) | 1 | Show full balcony condition |
| Before (detail) | 1 | Show specific issues (cracks, rust, old railing) |
| Process | 2 | Frame install, glass panel fitting |
| After (wide) | 2 | From inside looking out, from outside looking in |
| After (detail) | 3 | Glass edge, hardware, finish quality |
| After (lifestyle) | 1 | Furnished balcony showing use |
| Comparison pair | 1 | Same angle before/after |

### Waterproofing

| Category | Minimum Shots | Notes |
|---|---|---|
| Before (wide) | 1 | Show affected area |
| Before (detail) | 2 | Water stains, cracks, active leaks |
| Process | 3 | Surface prep, membrane application, testing |
| After (wide) | 1 | Finished surface |
| After (detail) | 2 | Edge sealing, finished corners |
| Water test | 1 | Proof of waterproof (if possible) |

### Roofing

| Category | Minimum Shots | Notes |
|---|---|---|
| Before (wide) | 1 | Full roof view |
| Before (detail) | 2 | Damaged areas, rust, leaks |
| Process | 2 | Old material removal, new installation |
| After (wide) | 2 | Full roof, angled view |
| After (detail) | 3 | Edge flashing, seams, finish |

### Blinds / Zip Track

| Category | Minimum Shots | Notes |
|---|---|---|
| Before (wide) | 1 | Space before installation |
| Process | 2 | Mounting, mechanism install |
| After (wide) | 2 | Fully open, fully closed |
| After (detail) | 3 | Mechanism, fabric quality, track system |
| After (lifestyle) | 1 | In use (open/closed for effect) |

### Full Renovation

| Category | Minimum Shots | Notes |
|---|---|---|
| Before (per room) | 2 | Wide + detail of problem areas |
| Process | 4+ | Demolition, structural, rough-in, finishing |
| After (per room) | 3 | Wide, medium, detail |
| After (lifestyle) | 1 | Space in use |
| Comparison pairs | 1 per room | Same angle before/after |

## Priority Ranking for Shoots

When time or access is limited, capture in this order:

1. **Before shots** — cannot be recreated once work starts
2. **After wide shots** — essential for galleries
3. **Comparison pairs** — highest conversion value
4. **Detail shots** — prove quality
5. **Process shots** — build trust
6. **Lifestyle shots** — nice to have

---

## Notes

- Always get client permission before photographing their property
- Coordinate with project manager for best timing
- Capture more than minimum when possible — extra shots are cheap, missing shots are expensive
- Log all shots in a shoot manifest for tracking
