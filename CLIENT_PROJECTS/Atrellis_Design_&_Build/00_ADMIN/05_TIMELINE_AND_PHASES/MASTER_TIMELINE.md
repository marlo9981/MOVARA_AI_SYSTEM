## Phase 0 — Planning & Architecture (Current)

### Objectives
- Build complete documentation skeleton across all 13 top-level folders
- Write source-of-truth markdown files for backbone folders
- Establish repo mirroring logic
- Define prompt and agent systems
- Create content and SEO architecture plan

### Priority sequence
1. `00_ADMIN` — Project control layer
2. `02_WEBSITE_STRUCTURE` — Site map, navigation, user journeys, CTA system
3. `05_CONTENT_SEO_AIO` — Topic clusters, keyword map, blog engine, AIO blocks
4. `09_BUILD_SYSTEM` — Repo architecture, app router map, component system, data model
5. `11_PROMPTS_AND_AGENTS` — Atrellis prompts, Claude/Gemini rules, agent handoff

### Completion criteria
- [ ] All 13 top-level folders have complete subfolder structures
- [ ] Backbone folders (00, 02, 05, 09, 11) have populated README and MASTER files
- [ ] Repo mirroring map is defined and documented
- [ ] Prompt system is functional and tested
- [ ] Client has reviewed and approved the overall direction

## Timeline principles

1. Phases are sequential but can overlap at boundaries
2. Dates are targets, not commitments — update honestly
3. Each phase must meet its completion criteria before the next phase starts in earnest
4. Scope changes within a phase should be documented in the decision log
5. Scope changes that affect phase boundaries require client approval
