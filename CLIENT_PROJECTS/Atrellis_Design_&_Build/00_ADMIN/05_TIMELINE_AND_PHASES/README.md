# 05_TIMELINE_AND_PHASES

## Purpose

This folder defines the project timeline, phase breakdown, milestones, and deadlines for the Atrellis Design & Build project.

It provides a clear view of what should happen when, what depends on what, and what "done" looks like at each stage.

## What belongs here

- Master timeline and Gantt-style overview
- Phase definitions and boundaries
- Milestone list with target dates
- Dependency mapping between phases

## What does not belong here

- Daily task tracking (goes in `09_BUILD_SYSTEM/08_TASKS_AND_SPRINTS/`)
- Meeting-by-meeting progress notes (goes in `06_MEETINGS_AND_NOTES/`)
- Detailed sprint plans (goes in `09_BUILD_SYSTEM/08_TASKS_AND_SPRINTS/`)

## Core files in this folder

- `MASTER_TIMELINE.md`
- `PHASE_BREAKDOWN.md`
- `MILESTONES_AND_DEADLINES.md`
- `NOTES.md`

## Source of truth

The main source of truth is:

- `MASTER_TIMELINE.md`

## Usage rules

- Update this folder when phases shift or milestones are hit
- Keep phase definitions stable — don't redefine phases mid-stream without a decision log entry
- Milestones should be specific and measurable
- Dates should be treated as targets, not commitments — update them honestly when reality changes

## Relationship to other folders

- Phase execution connects to `09_BUILD_SYSTEM/08_TASKS_AND_SPRINTS/`
- Decision-driven timeline changes connect to `03_DECISION_LOG/`
- Current status connects to `02_PROJECT_STATE/`
