# 06_MEETINGS_AND_NOTES

## Purpose

This folder captures meeting logs, working session summaries, and ideas/actions that emerge during the Atrellis project.

It provides a searchable record of what was discussed, what was decided, and what actions were assigned.

## What belongs here

- Meeting logs with date, attendees, and outcomes
- Working session summaries (AI or human sessions)
- Captured ideas and action items
- Informal notes that don't yet belong in a source-of-truth file

## What does not belong here

- Formal decisions (go in `03_DECISION_LOG/`)
- Project state updates (go in `02_PROJECT_STATE/`)
- Strategic direction documents (go in `01_PROJECT_OVERVIEW/`)

## Core files in this folder

- `MEETING_LOG_INDEX.md`
- `WORKING_SESSION_SUMMARIES.md`
- `CAPTURED_IDEAS_AND_ACTIONS.md`
- `NOTES.md`

## Source of truth

The main source of truth is:

- `MEETING_LOG_INDEX.md`

## Usage rules

- Every meeting or working session should get a dated entry
- Action items should be clear and assigned to a specific person or agent
- Ideas should be captured freely but then routed to the correct folder when they become actionable
- This folder should not become a graveyard — regularly clean up and route content to its proper home

## Relationship to other folders

- Decisions made in meetings should be logged in `03_DECISION_LOG/`
- Action items that become tasks should go in `09_BUILD_SYSTEM/08_TASKS_AND_SPRINTS/`
- Strategic ideas should be routed to the relevant domain folder
