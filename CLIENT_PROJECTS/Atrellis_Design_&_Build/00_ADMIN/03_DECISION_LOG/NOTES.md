# Notes

Temporary decision-related notes go here.

Possible entries:
- decisions that are forming but not yet formalized
- questions about whether something qualifies as a decision
- reminders to log decisions that were made in conversation
- notes about decisions that need to be revisited

Move anything stable into:
- `DECISION_LOG_MASTER.md` (finalized decisions)
- `OPEN_DECISIONS.md` (unresolved decisions)
- `SUPERSEDED_DECISIONS.md` (reversed decisions)
