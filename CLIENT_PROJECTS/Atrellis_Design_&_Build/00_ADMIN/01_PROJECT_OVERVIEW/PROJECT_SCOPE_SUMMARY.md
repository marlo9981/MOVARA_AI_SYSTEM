# Project Scope Summary
**Status:** Draft — confirm with project lead
**Last Updated:** 2026-04-05

---

## In Scope

### Website
- Full design and development of the Atrellis public-facing website
- Homepage, Services hub, Products pages, Projects/Blog, About, Contact
- Mobile-responsive layout across all pages
- SEO/AIO optimised page structure and metadata
- Lead capture and qualification flow (forms, CTAs)
- Media integration (real project imagery and product photography)

### Content
- Page-level copy for all core pages
- Service and product category pages (zipblinds, waterproofing, roofing, blinds, paint, balcony, full reno)
- Blog/editorial content — initial batch to support topical authority
- FAQ and answer-block content for AIO readiness

### AI & Automation (Phase 1)
- AI assistant on-site for basic lead guidance
- Lead qualification flow (question-and-answer intake)
- Basic follow-up automation

### Technical Foundation
- Next.js App Router application
- Clean URL/slug structure ready for future platform expansion
- Analytics integration
- Performance and Core Web Vitals baseline

---

## Out of Scope (Phase 1)

- Client portal / logged-in customer experience
- Automated quote generation engine
- Floorplan-to-render configurator
- CRM backend integration (deferred to Phase 2)
- E-commerce / online payments
- Multi-language support
