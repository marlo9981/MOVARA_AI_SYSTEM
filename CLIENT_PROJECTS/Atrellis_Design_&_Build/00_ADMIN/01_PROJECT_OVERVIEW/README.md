# 01_PROJECT_OVERVIEW

## Purpose
This folder is the top-level onboarding context for the entire Atrellis project. Anyone — human or AI — reading this folder should come away with a clear, plain-English understanding of what Atrellis is, what this project is trying to achieve, and what the current scope covers.

## What Belongs Here
- Plain-English overview of the Atrellis company and brand
- Project goals, business objectives, and website objectives
- High-level scope definition (what is in, what is out)
- Working notes related to overview-level questions

## What Does NOT Belong Here
- Tactical timelines or sprint planning → `05_TIMELINE_AND_PHASES/`
- Decision history → `03_DECISION_LOG/`
- Stakeholder roles → `04_STAKEHOLDERS/`
- Brand positioning or voice → `01_BRAND_FOUNDATION/`

## Files in This Folder

| File | Role |
|---|---|
| `ATRELLIS_PROJECT_OVERVIEW.md` | SOURCE OF TRUTH — canonical overview of Atrellis and this project |
| `PROJECT_SCOPE_SUMMARY.md` | What is in scope, what is out of scope, and key constraints |
| `WEBSITE_AND_PLATFORM_OBJECTIVES.md` | The specific business and website goals this project must deliver |
| `NOTES.md` | Rough working notes, open questions, and early-stage thinking |
