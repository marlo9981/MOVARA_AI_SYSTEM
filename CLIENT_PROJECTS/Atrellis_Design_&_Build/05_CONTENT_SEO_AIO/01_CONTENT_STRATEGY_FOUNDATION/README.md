# Content Strategy Foundation

This folder defines the strategic bedrock for all Atrellis content. It ensures that every word written serves the brand storyboard, aligns with service categories, and drives users toward platform-led conversion.

### File Overview
- **01_CONTENT_STRATEGY_FOUNDATION.md**: Core objectives, principles, and the role of content in the Atrellis ecosystem.
- **02_PILLARS_AND_TOPICS.md**: Long-term content themes and topic cluster shapes that map to service categories.
- **03_TONE_AND_FORMAT_RULES.md**: Practical guidelines for voice, tone, and visual formatting across different contexts.
- **NOTES.md**: A parking lot for assumptions, open questions, and future expansion ideas.

### When to use this folder
- During the planning phase of new content campaigns.
- When reviewing the content roadmap for alignment with `04_SERVICE_CATEGORY_SYSTEM`.
- When onboarding new writers or AI-ops specialists to the Atrellis system.
