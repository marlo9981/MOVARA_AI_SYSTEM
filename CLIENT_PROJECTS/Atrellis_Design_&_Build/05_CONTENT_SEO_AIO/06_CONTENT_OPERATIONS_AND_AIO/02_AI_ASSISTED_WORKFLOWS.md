# AI Assisted Workflows

## AI as a System Tool
AI is used to accelerate production while adhering to the Atrellis "containers."

### Example Meta-Prompts

#### 1. Service Page Drafter
> "Using the Atrellis 'Premium, Calm, Competent' tone, draft a Service Page for [SERVICE NAME]. Use the following blocks: Hero, Scope (bulleted), Process (numbered), and FAQ. Ensure it aligns with the [CATEGORY NAME] category. Focus on clarity and conversion."

#### 2. Pillar Hub Outline
> "Create a structural outline for a Content Library Hub titled '[HUB TITLE]'. Map the hub to the [PILLAR NAME] pillar and suggest 5 'spoke' articles that address common user anxieties regarding this topic."

#### 3. Tone Refactor
> "Rewrite the following draft to sound more 'Competent and Reassuring'. Remove all fluff, shorten paragraphs to 3 sentences max, and ensure it sounds digitally-capable but human."

## Dos and Don'ts
- **DO**: Anchor every prompt to a specific Category and Template.
- **DON'T**: Allow AI to generate new page structures or navigation paths.
- **DO**: Use AI for QA (e.g., "Check this markdown against the Atrellis On-Page Checklist").
