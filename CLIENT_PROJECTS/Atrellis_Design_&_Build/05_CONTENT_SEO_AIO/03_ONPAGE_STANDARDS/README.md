# On-Page Standards

This folder provides the "specs" for creating high-performing, on-brand pages. It is the primary reference for anyone drafting content for the Atrellis website.

### File Overview
- **01_ONPAGE_CHECKLIST.md**: A universal quality check for all content.
- **02_SERVICE_AND_LOCATION_PAGES.md**: Standards for transactional landing pages.
- **03_CONTENT_BLOCK_SEO_RULES.md**: SEO and UX guidance for modular design blocks.
- **NOTES.md**: Real-world examples and automation ideas.

### Utility
- Ensures consistency across `04_SERVICE_CATEGORY_SYSTEM` templates.
- Aligns with the visual language defined in the design system.
