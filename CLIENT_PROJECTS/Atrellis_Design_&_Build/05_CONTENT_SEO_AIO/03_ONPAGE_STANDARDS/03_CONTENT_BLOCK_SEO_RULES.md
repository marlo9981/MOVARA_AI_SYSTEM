# Content Block SEO Rules

Our modular design blocks are optimized for both user clarity and search engine understanding.

### 1. Hero Block
- **Purpose**: Immediate orientation.
- **SEO**: Use the primary H1 here. Keep text concise to ensure fast mobile loading.

### 2. Scope Block
- **Purpose**: Define boundaries.
- **SEO**: Use bulleted lists (UL/LI) to help search engines parse the specific services offered.

### 3. Process Block
- **Purpose**: Build trust through systems.
- **SEO**: Use numbered lists (OL/LI) to signal a structured methodology (e.g., Step 1: Design, Step 2: Build).

### 4. Proof/Testimonial Block
- **Purpose**: Third-party validation.
- **SEO**: Use `Review` schema where possible. Ensure names and locations are marked up.

### 5. FAQ Block
- **Purpose**: Address anxieties.
- **SEO**: Use `FAQPage` schema. This is a primary opportunity for Rich Results.

### 6. CTA Block
- **Purpose**: Direction.
- **SEO**: Buttons should use descriptive text (e.g., "Start Your Kitchen Quote" instead of "Click Here").
