# SEO Architecture

This folder governs how SEO is baked into the structural DNA of Atrellis. We view SEO as a framework for Information Architecture (IA) and user navigation, not as an afterthought.

### File Overview
- **01_SEO_SITE_ARCHITECTURE.md**: The hierarchy of pages from homepage to tools.
- **02_KEYWORD_AND_INTENT_MAP.md**: Mapping user intent to page types and CTAs.
- **03_INTERNAL_LINKING_RULES.md**: The "rails" that guide users and search engines through the site.
- **NOTES.md**: Risks, watch-outs, and experiment logs.

### Connections
- Relates directly to `02_WEBSITE_STRUCTURE` (Sitemap & Nav).
- Inherits service categories from `04_SERVICE_CATEGORY_SYSTEM`.
