# SEO Architecture Notes

## Risks & Watch-outs
- **Cannibalization**: Ensure that Category Hubs and Service Pages don't compete for the same broad keywords.
- **Over-linking**: Avoid footer link clouds or header "mega-menus" that dilute link equity.

## Triggers for Revision
- Adding a new Master Service Category in `04_SERVICE_CATEGORY_SYSTEM`.
- Launching a major public-facing tool (e.g., the public Configurator).
