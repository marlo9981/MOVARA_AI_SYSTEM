# Keyword and Intent Map

## Intent Categories
We map keywords to four distinct stages of the user journey:

### 1. Informational (Early Research)
- **Goal**: Understand the design-build process or find inspiration.
- **Page Types**: Library articles, Guides, Pillar Hubs.
- **CTA**: Download Guide, Sign up for Newsletter.

### 2. Consideration (Solution Seeking)
- **Goal**: Compare services and evaluate Atrellis’s methodology.
- **Page Types**: Category Hubs, Service Templates.
- **CTA**: View Portfolio, Read Process Guide.

### 3. Transactional (Ready to Act)
- **Goal**: Request a quote or start a project.
- **Page Types**: Service Pages, Pricing/Package Pages.
- **CTA**: Start Your Quote, Book a Call.

### 4. Tool-Oriented (Platform Engagement)
- **Goal**: Use a specific Atrellis digital feature.
- **Page Types**: Configurator Entry, Floorplan Uploader.
- **CTA**: Launch Tool, Save Progress.

## Mapping Logic
- Keywords are grouped by **Service Category** and **Intent**.
- We focus on "Thematic Clusters" rather than individual keyword targets.
- High-intent keywords (e.g., "Design-build renovation London") must land on a transactional Service Page.
