# Media and Rich Content Rules

## Visual Assets
- **Photography**: High-resolution, professional project photos.
- **Renders**: Clearly marked as "Atrellis Visualisation" to build tech trust.
- **Diagrams**: Used for explaining complex processes or structural concepts.

## Interactive Content
- **Calculators**: Simple budget or square-footage estimators.
- **Galleries**: Filterable by "Service Category" or "Style" to match user intent.
- **Video**: Short, high-quality clips showing "The Atrellis Experience" or tool tutorials.

## SEO for Rich Content
- **Alt-Text**: Must be descriptive and include the Service Category.
- **Lazy Loading**: Mandatory for all image-heavy galleries.
- **Captions**: Every rich media element must be accompanied by text that search engines can read.
