# Topic Cluster Playbook

## The Hub-and-Spoke Model
We organize library content into clusters to dominate specific renovation themes.

### Cluster Structure
1. **The Hub**: A definitive guide (e.g., "The Complete Guide to Modern Extensions").
2. **The Spokes**: Specific articles that link back to the hub (e.g., "Cost of Glass Box Extensions," "Planning Permission for Two-Story Extensions").
3. **The Connection**: The Hub links to the "Extension" Service Category in `04_SERVICE_CATEGORY_SYSTEM`.

## Cluster Rules
- **When to start a hub**: When a topic has at least 5 distinct sub-questions that warrant 500+ words each.
- **Anchor Text**: Use consistent, descriptive anchor text when linking spokes to hubs.
- **Cross-Linking**: Spokes within the same cluster should link to each other where helpful.
