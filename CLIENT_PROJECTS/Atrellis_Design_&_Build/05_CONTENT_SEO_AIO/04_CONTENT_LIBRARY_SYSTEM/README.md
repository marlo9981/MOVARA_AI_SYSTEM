# Content Library System

This folder governs the non-transactional layer of Atrellis: the blogs, guides, and resources that build authority and capture early-stage interest.

### File Overview
- **01_CONTENT_LIBRARY_MODEL.md**: The philosophy and types of library content.
- **02_TOPIC_CLUSTER_PLAYBOOK.md**: How we build clusters around renovation themes.
- **03_MEDIA_AND_RICH_CONTENT_RULES.md**: Guidance for images, video, and tools.
- **NOTES.md**: Cluster patterns and future tool integration ideas.
