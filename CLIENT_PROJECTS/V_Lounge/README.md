# V Lounge

Premium cocktail bar website — dark, atmospheric, conversion-focused.

## Status: PLANNING

## What We're Building

A marketing website for V Lounge, a cocktail bar. The site needs to communicate the atmosphere and drive reservations. Mobile-first since most traffic will come from social media and local search.

## Pages

| Page | Purpose |
|------|---------|
| Home | Hero + atmosphere, signature drinks preview, CTA |
| Menu | Full cocktail menu, categorized |
| Events | Upcoming events, recurring nights, private hire |
| About | Brand story, team |
| Gallery | Photo showcase |
| Contact | Location, hours, reservation form |

## Tech Stack

- Next.js App Router (TypeScript)
- Tailwind CSS
- GSAP + ScrollTrigger
- Supabase (reservations, events CMS)
- Vercel

## Design Notes

- Dark palette: black, deep purple, gold, warm amber
- Elegant serif headings, clean sans body
- Atmospheric photography emphasis
- Smooth animations, nothing flashy
