CLAUDE GUIDELINES – 03_SALES_PROCESS

PURPOSE OF THIS FOLDER
This folder defines how Movara AI sells: the funnel stages, discovery process, demos, proposals, objection handling, and follow-up. The goal is to have a simple, repeatable system for B2B founder-led sales in SEA.

FILES IN THIS FOLDER

- Sales_Funnel_and_Stages
- Discovery_Call_Script_and_Notes
- Objection_Handling_Plays
- Proposal_and_Followup_Process (optional later)
- Any additional sales assets we decide to standardise

RULES

1. Keep everything step-by-step and usable during real calls.
2. Use our ICP and positioning from 01_STRATEGY when writing scripts.
3. Focus on clarity and next steps, not fancy language.
4. Update these docs based on real calls and deals; they should evolve.
5. Do not create new structure without updating this CLAUDE doc.
