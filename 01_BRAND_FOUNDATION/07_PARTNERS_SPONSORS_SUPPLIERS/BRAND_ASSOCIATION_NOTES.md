# Brand Association Notes

## Purpose

This file explains how Atrellis should think about brand associations.

Brand associations can increase trust, but only if they are used carefully.

## What a good brand association does

A good association helps a visitor feel:
- this brand is credible
- this brand understands quality
- this brand is connected to serious products or systems
- this brand feels more trustworthy than a generic operator

## What a bad brand association does

A bad association makes the brand feel:
- inflated
- dependent on someone else's credibility
- cluttered
- unclear
- desperate for borrowed trust

## Association categories

### 1. Quality-assurance associations
These support the idea that Atrellis uses known or trusted systems and materials.

### 2. Ecosystem associations
These show that Atrellis operates within a wider network of recognized suppliers, brands, or collaborators.

### 3. Conversion-support associations
These reduce hesitation for customers who need proof that Atrellis is not just an unknown operator.

## Messaging rule

When mentioning associated brands, the message should imply:
Atrellis is informed, credible, and quality-aware.

It should not imply:
Atrellis has no authority of its own.

## Visual rule

External brand references should be clean and restrained.

Avoid:
- messy logo clutter
- oversized logo grids
- irrelevant brand dumping
- showing brands with no clear explanation

## Strategic rule

Every brand association should answer one of these questions:

- Does this increase trust?
- Does this clarify quality?
- Does this support a category-specific decision?
- Does this reduce hesitation?

If not, it may not need to be included.
