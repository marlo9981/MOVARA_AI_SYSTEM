# 04_PROJECTS_BLOGS

## Purpose

This folder defines the projects and blogs page system for Atrellis.

Its role is to explain:
- how work examples and content should be structured,
- how authority should be built,
- how educational and proof content should support conversion,
- and how projects and blogs should connect back to services and products.

This folder matters because projects and blogs are not just content.
They are trust, authority, and relevance assets.

## What belongs here

- Projects/blogs page purpose
- Authority-content logic
- Relationship between proof and education
- Routing from content into services/products/inquiry
- Content page system role

## What does not belong here

- Final article drafts
- Full case-study production templates
- Analytics dashboards
- Deep SEO research spreadsheets
- Raw content idea dumps with no page-system logic

Those belong elsewhere.

## Core files in this folder

- `PROJECTS_BLOGS_MASTER.md`
- `AUTHORITY_CONTENT_LOGIC.md`
- `PROJECTS_BLOGS_CONVERSION_ROLE.md`
- `NOTES.md`

## Source of truth

The main source of truth is:

- `PROJECTS_BLOGS_MASTER.md`

## Usage rules

- Treat projects and blogs as authority assets.
- Make content strategically connected to core conversion paths.
- Use proof and education together.
- Avoid turning content into isolated dead-end pages.
