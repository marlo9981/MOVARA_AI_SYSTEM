# Projects Blogs Master

## Core role

The projects and blogs system should build authority, trust, and relevance.

It should help users:
- see what Atrellis has done
- understand how Atrellis thinks
- feel more confident in the brand
- move toward more relevant service or product pages

## Main jobs of the page type

This page type should:

- showcase selected proof
- provide useful content
- support SEO and AIO visibility
- answer user questions
- increase confidence before inquiry
- route users toward higher-intent pages

## What this page type should not do

It should not:
- become content for content's sake
- feel disconnected from the conversion system
- publish weak generic articles
- present proof with no strategic framing

## Success criteria

A strong projects/blogs system should make the user feel:

- this brand knows what it is doing
- they seem more credible than generic competitors
- this content is actually useful
- I trust them more after reading or viewing this
