# Service Landing Conversion Role

## Core role

The services landing page should convert broad interest into specific relevance and then into inquiry readiness.

## Main conversion outcomes

This page should move users toward:
- category pages
- trust-support pages
- direct inquiry when appropriate

## Best CTA logic

CTA should be mixed:

- relevance CTAs to deeper service areas
- selective inquiry CTAs for ready users

Examples:
- Explore this category
- Discuss your project
- Find the right solution

## Conversion warning

Do not force high-intent CTA on every section equally.

Some users need:
- clarity first
- category match second
- action third

## Evaluation rule

Judge this page by:
- how clearly it groups services
- how well it routes users
- how well it reduces breadth confusion
- how effectively it creates next-step momentum
