# 02_SERVICE_LANDING

## Purpose

This folder defines the main service landing page system for Atrellis.

Its role is to explain:
- how broad service offerings should be presented,
- how service groups should be structured,
- how users should move from broad services into specific relevance,
- and how the service landing page should support one-stop positioning without becoming cluttered.

This folder is important because Atrellis spans multiple services and needs a controlled page system that explains breadth clearly.

## What belongs here

- Service landing page purpose
- Service grouping logic
- Section architecture
- Routing from broad services to specific categories
- Conversion role of the services page

## What does not belong here

- Full service-detail specs
- Individual service page copy
- Product-system-only logic
- Technical implementation details
- Raw brainstorm lists of every service

Those belong elsewhere.

## Core files in this folder

- `SERVICE_LANDING_MASTER.md`
- `SERVICE_GROUPING_LOGIC.md`
- `SERVICE_LANDING_CONVERSION_ROLE.md`
- `NOTES.md`

## Source of truth

The main source of truth is:

- `SERVICE_LANDING_MASTER.md`

## Usage rules

- Broad services should feel organized.
- Grouping should reduce confusion.
- The page should support both discovery and confidence.
- Do not turn the page into a giant list.
