# 01_HOME

## Purpose

This folder defines the Atrellis homepage as a page system.

Its role is to explain:
- what the homepage must do,
- what sections it should contain,
- how it should guide users,
- and how it should balance brand, trust, breadth, and conversion.

This folder is important because the homepage is the main orientation layer for broad visitors.

## What belongs here

- Homepage purpose and role
- Homepage section architecture
- Homepage content priorities
- Routing and conversion logic
- Trust and relevance requirements

## What does not belong here

- Final design comps
- Full production copy
- Deep component implementation notes
- Technical code details
- Isolated microcopy experiments

Those belong elsewhere.

## Core files in this folder

- `HOME_MASTER.md`
- `HOME_SECTION_ARCHITECTURE.md`
- `HOME_CONVERSION_ROLE.md`
- `NOTES.md`

## Source of truth

The main source of truth is:

- `HOME_MASTER.md`

## Usage rules

- The homepage should orient, not overload.
- It should feel broad but controlled.
- It should route users into relevance quickly.
- It should support both trust and conversion.

## Relationship to other folders

This folder supports:
- `02_WEBSITE_STRUCTURE/`
- `04_SERVICE_CATEGORY_SYSTEM/`
- `05_CONTENT_SEO_AIO/`
- `07_CONVERSION_ARCHITECTURE/`

The homepage is the top-level public entry page for Atrellis.
