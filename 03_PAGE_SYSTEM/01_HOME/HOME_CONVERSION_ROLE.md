# Home Conversion Role

## Core role

The homepage should support conversion by improving clarity and trust, then routing users into the right next step.

## What the homepage should convert into

The homepage should not only aim for direct contact.

It should also convert users into:
- deeper service exploration
- product/system exploration
- proof-content exploration
- trust-building page visits
- inquiry readiness

## Best CTA logic

Recommended CTA pattern:
- one primary CTA for action
- one secondary CTA for relevance discovery

Examples:
- Start your inquiry
- Explore services

## Conversion warning

The homepage should not assume every visitor is equally ready.

Some need:
- direct action
- others need deeper understanding first

## Performance rule

Judge homepage success by:
- clarity
- routing quality
- trust-building strength
- progression into relevant next pages
- not only last-click contact conversions
