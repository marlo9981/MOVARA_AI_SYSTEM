# System Category Logic

## Core principle

Product-system categories should be structured around how users think, not only around internal business labels.

## Recommended system logic

System pages should help users understand:
- what the system is
- where it fits
- why someone chooses it
- what options or variations matter
- what next step makes sense

## Likely category examples

Examples may include:
- zipblinds
- pergolas
- roofing systems
- blinds systems
- enclosure-related systems
- weather-protection solutions

## Page logic rule

A product/system page should balance:
- explanation
- confidence
- trust
- and action

## Strategic rule

The products area should support:
- search intent capture
- authority building
- higher-intent lead generation
- future guided selection flows
