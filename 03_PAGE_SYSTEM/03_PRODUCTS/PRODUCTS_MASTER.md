# Products Master

## Core role

The products / systems page should help users evaluate system-led offerings more clearly.

It should support visitors who are not just looking for a broad contractor.
They are often looking for a specific solution type.

## Main jobs of the page

The page should:

- explain product-system categories clearly
- support direct-intent traffic
- show authority and understanding
- help users compare or interpret options
- guide users toward the right next step

## What this page type should not do

It should not:
- read like a raw catalog
- become a cluttered product dump
- lose the Atrellis premium brand framing
- ignore the wider design-build context

## Success criteria

A good products page should make the user feel:

- this is relevant to what I'm searching for
- they understand this category
- this feels more premium and organized than generic category pages
- I know how to move forward
