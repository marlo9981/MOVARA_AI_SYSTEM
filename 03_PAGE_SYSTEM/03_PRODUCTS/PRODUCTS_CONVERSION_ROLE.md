# Products Conversion Role

## Core role

The products / systems page should convert specific interest into structured action.

## Main conversion outcomes

This page should move users toward:
- category-specific inquiry
- advice request
- future quote or guided flow
- related service exploration where relevant

## Best CTA logic

Because intent is often stronger here, CTA can be more action-oriented than on broad pages.

Examples:
- Ask about this system
- Get advice for your space
- Explore the right option
- Start your inquiry

## Conversion rule

Higher intent does not remove the need for trust.

These pages should still provide:
- reassurance
- useful explanation
- confidence-building cues

## Evaluation rule

Judge success by:
- relevance match
- clarity of system explanation
- inquiry progression
- support for future high-value flows
